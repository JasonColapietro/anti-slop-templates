Using these

Take one,
commit to it.

  1. i

    Open any file

    Every page is self-contained HTML. Double-click it, or serve the folder. No install, no build.

  2. ii

    Edit the tokens, not the pages

    Each system's look lives in styles/tokens.css. Change the palette or type there and all four surfaces follow.

  3. iii

    Port when ready

    The markup maps 1:1 onto Tailwind utilities or JSX components. The CSS-variable scale is the contract.
