What's on the desk

Tools that defer to the writing,

01

The typographic editor

Optical sizing, real small caps, hung punctuation and a measure you set yourself. The draft already reads like the printed page—because it is set like one.

02

Local-first archive

Every draft is a plain text file on your disk. Sync if you like, leave if you like. Nothing is hostage to a server.

03

Revision as a record

Track the sentence that changed, not a diff of noise. See the draft the way an editor would.

04

Focus that means it

No counters, no streaks, no nudges. The chrome recedes until the page is the only lit thing in the room.
